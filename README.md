## 🚀 Getting Started
Welcome to railOne, a Flutter project designed to help you book and track train tickets easily. This application connects you with railway services, making train travel more accessible. Follow the steps below to download and run the app.

## 💡 Features
- **User-Friendly Booking**: Easily search for and book train tickets.
- **Live Tracking**: Get real-time updates on train locations.
- **PNR Status**: Check your booking status at any time.
- **Cross-Platform**: Access the app on various devices.
- **Secure Login**: Use Firebase authentication for a safe experience.

## 📜 System Requirements
- **Operating System**: Windows 10/11, macOS, or Linux
- **Storage**: At least 100 MB of free space
- **Internet Connection**: Required for downloading and using the app
